# docs/history/ — the record of how the project got here

Read-only history. **Nothing here is read at the start of a session** (ADR-0110);
it is searched when a question needs the reasoning behind something.

| File | What it is |
|---|---|
| `HANDOFF-S001-S023.md` | The handover as it stood when the process was slimmed on 2026-10-07: every session's summary from S001 to S023, the open-question table (`HANDOFF Q1`–`Q28`, which older ADRs cite), and the "do not redo" list, now condensed into `docs/RULES-IN-FORCE.md` |

**What belongs here:** a document that has stopped being current but is still
cited. **What does not:** anything a session must act on — that goes in
`docs/HANDOFF.md` — and anything that is still a rule, which goes in
`docs/RULES-IN-FORCE.md` and the ADR behind it.

Never edit a file here to make it current. Write the current version elsewhere.
