# data/derived/links/ — which passages name which concept (free, deterministic)

Written by `tmk-bulk links --write`. `mentions.json`: every whole-word match of a
concept's labels in a Manual passage. `pairs.json`: concept pairs the Manual
mentions together, the candidates the relationship job asks a model about. No
model and no judgement, so nothing here needs review — and nothing here is a
relationship: a pair is a question, not an answer.
